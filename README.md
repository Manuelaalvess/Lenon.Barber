# Lenon Barber

Site hub mobile-first para o barbeiro Lenon: agendamento, apresentação dos serviços e contato a partir do link da bio.

**Deploy:** [lenonbarber-snowy.vercel.app](https://lenonbarber-snowy.vercel.app)

**Stack:** Vite, React, TypeScript, Tailwind CSS, React Router.

## Rotas

- `/` — Home com agendamento e navegação
- `/trabalho` — Sobre mim, serviços, galeria e perguntas frequentes
- `/contato` — WhatsApp, Instagram, endereço, mapa e horário

## Desenvolvimento

```bash
npm install
npm run dev
npm run build
```
